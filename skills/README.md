# Agent Skills

A curated collection of agent skills for AI coding assistants (GitHub Copilot,
Cursor, etc.).

Install all skills from the [repository](https://github.com/ak1ra-komj/agents-skills):

```bash
npx skills add ak1ra-komj/agents-skills
```

For local and global installation, authoring guidance, and reference documents,
see the [repository README](https://github.com/ak1ra-komj/agents-skills#readme).

## Skills

| Skill                                                                     | Purpose                                                        |
| ------------------------------------------------------------------------- | -------------------------------------------------------------- |

| [developing-ansible](developing-ansible/SKILL.md)                         | Write and review Ansible playbooks, roles, tasks, and plugins. |

| [developing-posix-shell-scripts](developing-posix-shell-scripts/SKILL.md) | Write and review portable POSIX shell scripts.                 |
